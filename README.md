# SillyTavern Modern

A complete SillyTavern installation with the Modern Tavern interface bundled in.
The original SillyTavern backend, data formats, advanced interface, and power-user
features remain available.

## Quick installation

Install Node.js 20 or newer, then clone and start the app:

```text
git clone https://github.com/Yruzan/SillyTavern-Modern-Full.git
cd SillyTavern-Modern-Full
npm install
npm start
```

On Windows, you can clone with GitHub Desktop and run `Start.bat`. Open the local
address printed by the launcher, normally http://localhost:8000.

This is a private repository, so GitHub authentication is required. No API keys,
characters, chats, or other user data are included.

## Modern Tavern

The redesigned experience includes a responsive app shell, homepage, creation
menu, character library, recent chats, modern chat layout, mobile navigation,
Focus Mode, prompt snapshots, and Theme Studio. Choose **SillyTavern Advanced**
at any time to access the complete original interface.

For implementation notes, compatibility details, and current prototype limits,
see [MODERN-TAVERN.md](MODERN-TAVERN.md).

## Upstream SillyTavern

SillyTavern is an LLM frontend for power users. This project is based on the
official SillyTavern codebase and keeps its AGPL-3.0 license.
